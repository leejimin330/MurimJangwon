# 무림장원 — 5단계: 습격전 설계

작성일: 2026-10-27
상태: 구현·검증 완료 (2026-10-27, 사용자가 "5단계까지 쭉" 진행을 맡겨 검토 없이 추천안으로 확정)
선행:
- [3단계 설계](2026-10-26-murim-stage3-martial-arts-design.md) — 카드, `Duel` 수치
- [4단계 설계](2026-10-27-murim-stage4-manor-design.md) — 장원 격자, 담장·망루

## 1. 목표

습격 사건이 플레이어 세력을 덮치면 **장원 격자 위에서 실시간 + 일시정지 전투**가 벌어진다. 플레이어는 인물을 골라 위치와 상대만 지정하고(림월드식 가벼운 조작), 나머지는 인물들이 무공 카드로 알아서 싸운다. 경지 차이가 그대로 힘의 차이가 된다.

5단계가 끝나면 플레이어는:
- 습격 사건에서 "맞서 싸운다"를 고르면 "습격!" 창에서 **직접 지휘** 또는 **자동으로 맞선다**를 고른다.
- 직접 지휘하면 장원 지도가 열리고 습격자가 정문으로 몰려든다. 아군 점을 눌러 고르고(여럿은 끌어서), 빈 땅을 누르면 그리로 가고, 적을 누르면 그 적을 친다. 일시정지·1배·2배·3배.
- 인물마다 체력·내력 막대가 보이고, 쓰러진 인물은 회색이 된다. 오른쪽에 전투 기록이 흐른다("장삼이 '태극혜검'으로 산적 두목을 쓰러뜨렸다").
- 습격자 두목이 쓰러지거나 습격자 60%가 쓰러지면 남은 습격자는 달아난다. 아군이 모두 쓰러지면 진다. 3분(전투 시간)이 지나면 습격자는 물러난다.
- 끝나면 결과 창: 이겼는지, 쓰러진 사람 중 죽은 이와 다친 이, 잃은 문도. 연대기에 경과가 남는다.
- 담장은 길을 막고, 망루 위에 선 인물은 더 멀리·세게 친다.
- AI 세력끼리의 습격은 같은 엔진이 기본 장원(본당만)에서 자동으로 계산한다.

**포함하지 않는 것**
- 플레이어가 공격하는 쪽(남의 장원 습격). 6단계에서 다룬다.
- 카드를 직접 고르는 조작. 카드는 인물이 3단계 결투 AI로 고른다.

## 2. 아키텍처

```
Assets/Murim.Core/Battle/
  BattleUnit.cs     전투 단위 (인물 또는 이름 없는 문도·졸개)
  BattleMap.cs      장원 격자 → 막힌 칸, 망루 칸, 정문, A* 길찾기 (8방향)
  BattleState.cs    단위들, 시간, 기록, 끝 판정, 결과
  BattleSim.cs      고정 시간 0.1초 틱: 명령 처리, 자동 교전, 이동, 공격, 사기
  BattleSetup.cs    습격 → 양쪽 단위 배치
  RaidState.cs      저장되는 대기 습격 (WorldState.PendingRaid)
  RaidResolver.cs   결과 적용: 사상자, 문도 손실, 사건 갈래 효과, 연대기
Assets/Murim.View/UI/Screens/BattleScreen.cs
Assets/Murim.View/UI/Panels/RaidPrompt.cs
```

- Core는 UnityEngine을 쓰지 않는다. 전투 난수는 습격마다 정한 시드의 `GameRandom`(세계 난수에서 한 번 뽑는다) 하나만 쓴다. 화면 프레임 속도는 결과에 영향을 주지 않는다(화면은 0.1초 틱을 쌓아서 돌린다).
- 같은 시드·같은 명령(틱 번호와 함께)이면 같은 결과. 자동 해결은 명령 없이 끝까지 돌린다.

## 3. 전투 단위

| 항목 | 이름 있는 인물 | 문도·졸개 |
|---|---|---|
| 체력 | `Duel.MaxHp` | 40 |
| 내력 | `Duel.MaxForce`, 초당 +2 회복 | 20 |
| 덱 | `Duel.Deck` | 주먹질 |
| 경지 | 인물 경지 | 0 |
| 속도(칸/초) | 2.0 + 신법 성취 × 0.1 | 1.8 |
| 사거리 | 1.3 (암기 카드가 있으면 그 카드만 4) | 1.3 |
| 공격 간격 | 1.2초 | 1.5초 |

- 공격: 공격·절초 카드 중 내력이 되는 것을 3단계 결투 AI 가중치로 고른다. 내력이 모자라면 주먹질 기본 공격(내력 0). 피해 = 위력 × (1 + 성취/10) × 1.1^(경지 차) × 난수(0.65~1.35) × 표식 보정 × (망루 위면 1.2).
- 받는 쪽 반응: 회피 확률 0.15 + 0.02 × 신법 성취 − 0.05 × max(0, 공격자 경지 − 내 경지)(0.05~0.6)이면 피해 0. 아니면 방어 카드가 있고 내력이 되면 그 카드를 써서 피해 × 0.6.
- 체력 0 → 쓰러짐. 쓰러진 단위는 움직이지 않고 표적이 되지 않는다.
- 망루 칸 위 단위: 사거리 +2(암기만), 피해 ×1.2.

## 4. 지도와 배치

- 장원 격자 24×16. 완공된 건물 칸은 막힘(망루는 막히지 않고 올라설 수 있다). 미완공 건물은 막지 않는다.
- 습격자는 아래 가장자리(y=15)의 정문 주변 x 8~15에서 나타난다. 정문 칸은 언제나 비어 있다.
- 방어자는 본당 바로 아래(y=9~10, x=9~14)에 선다. AI 세력 습격은 기본 장원(본당만)을 쓴다.
- 길찾기: A*, 8방향(대각선은 양옆이 막히지 않을 때만), 비용 1/1.41. 길이 없으면 가장 가까운 닿는 칸으로.

## 5. 틱 처리 (0.1초)

1. 명령이 있으면 따른다: 이동 → 길을 따라 걷고, 닿으면 명령 끝. 공격 → 사거리 안이면 치고, 아니면 다가간다(1초마다 길 다시 찾기).
2. 명령이 없으면: 6칸 안 가장 가까운 적과 싸운다. 없으면 습격자는 본당으로 다가가고, 방어자는 제자리를 지킨다.
3. 사기: 습격자 두목이 쓰러지거나 습격자 60%가 쓰러지면 남은 습격자는 달아난다(정문으로 가서 사라짐).
4. 끝: 습격자 모두 쓰러짐·달아남 → 방어 승. 방어자 모두 쓰러짐 → 습격 승. 1800틱(3분) → 습격자 물러남(방어 승).

## 6. 습격 사건 (`raid` 효과)

```json
{ "raid": { "attacker": "boss", "target": "head", "grunts": 6, "allies": 3,
            "win": [ ... 방어자가 이겼을 때 ... ], "lose": [ ... ] } }
```

- `attacker` 역할이 두목. 그 세력의 살아 있는 성인 소속원 중 경지 높은 순으로 `allies`명이 함께 온다(두목이 새 인물이면 같은 수의 새 졸개 인물을 만들지 않고 이름 없는 졸개로 센다). 이름 없는 졸개 `grunts`명.
- 방어자: 대상 세력의 살아 있는 성인 소속원 중 경지 높은 순 최대 10명 + 이름 없는 문도 min(문도 수, 10)명. 폐관 중인 인물도 나온다.
- **대상이 플레이어 세력의 수장(플레이어)이면** 결과를 미루고 `WorldState.PendingRaid`에 저장한다. 사건 결과 문장은 "습격자들이 장원으로 몰려온다!". 갈래 효과는 전투가 끝난 뒤 적용한다. 이를 위해 `raid`는 선택지 효과의 **최상위**에만 둘 수 있다(검증).
- 그 밖이면 바로 자동 해결하고 갈래를 적용한다.
- 결과 적용(`RaidResolver`):
  - 쓰러진 이름 있는 인물: 25% 죽음(사인 "습격"), 나머지는 `injured` 6개월.
  - 쓰러진 이름 없는 문도·졸개: 그 세력 `UnnamedDisciples`에서 뺀다(졸개는 버린다).
  - 연대기: "흑룡방의 습격을 물리쳤다 (쓰러진 적 7, 아군 사망 1)" + 전투 기록(최대 20줄)을 경과로.
- 사건 데이터 변경: `faction_gang_raid`의 "맞서 싸운다"가 `raid`를 쓴다. 새 사건 2개: `raid_bandits`(산적떼가 장원을 노린다, 새 두목 + 졸개 8), `raid_grudge`(원한 품은 세력의 수장이 쳐들어온다, 원한 ≥ 60, 소속원 3 + 졸개 6). 둘 다 "맞서 싸운다"(raid) / "재물을 내주고 돌려보낸다"(은자 −, 명성 −).

## 7. 세션과 저장

- `GameSession.PendingRaid`가 있으면 `CanEndTurn`이 false다(사건처럼 먼저 끝내야 한다).
- `GameSession.StartBattle()` → `BattleState`(시드 고정). `GameSession.FinishRaid(BattleState)` → 결과 적용, `PendingRaid` 비움, 결과 요약 반환. `GameSession.AutoResolveRaid()` → 명령 없이 끝까지 돌려 `FinishRaid`.
- 테스트·시뮬레이션의 `AutoResolveEvents`는 습격도 자동 해결한다.
- 저장(saveVersion 5): `WorldState.PendingRaid`(사건 id, 선택지 번호, 효과 번호, 역할, 시드, 함께 오는 인물 id, 졸개 수). 전투 도중 상태는 저장하지 않는다(불러오면 습격 창부터 다시).

## 8. 화면

- **습격 창** (`RaidPrompt`): 사건 선택 창처럼 화면을 덮는다. "{세력}의 무리가 장원으로 몰려온다!" 양쪽 인원(이름 있는 인물·문도), "직접 지휘한다" / "자동으로 맞선다".
- **전투 화면** (`BattleScreen`):
  - 왼쪽: 장원 격자(4단계 화면과 같은 칸 크기), 건물, 단위 점(아군 파랑, 적 빨강, 두목·플레이어는 금 테두리), 점 위 체력 막대, 고른 단위는 밝은 테두리, 이동 목표 표시.
  - 조작: 아군 점 클릭 = 고르기(Shift = 더하기), 빈 칸 클릭 = 이동, 적 점 클릭 = 공격. "모두 고르기", "고른 것 풀기".
  - 위: 시간(남은 시간), 일시정지·1배·2배·3배, "자동으로 끝내기".
  - 오른쪽: 고른 인물 정보(이름, 경지, 체력·내력, 덱 카드 이름), 전투 기록.
  - 끝: 결과 패널 + "확인" → 게임 화면으로.
- 화면 요소 이름(시나리오용): `BattleGrid`, `Unit:{번호}`, `BattleLog`, `BattleResult`, 단추 "직접 지휘한다"·"자동으로 맞선다"·"확인"·"일시정지"·"1배"·"2배"·"3배"·"자동으로 끝내기".

## 9. 검증·테스트

- 길찾기: 담장으로 막힌 길을 돌아간다, 완전히 막히면 가장 가까운 칸, 대각선 모서리 통과 금지.
- 같은 시드·같은 명령이면 같은 결과(틱 수, 승패, 체력).
- 힘의 차이: 같은 인원에서 방어 쪽 경지 +2면 1000번 중 90% 이상 이긴다. 졸개 20명 대 절정 1명은 절정이 대부분 이긴다(경지 반영).
- 사기: 두목이 쓰러지면 습격자 모두 달아남 상태가 된다.
- 망루: 망루 위 암기 사거리 6.
- 명령: 이동 명령을 받은 단위가 그 칸에 닿는다, 공격 명령 대상만 친다.
- 사건: 플레이어 대상이면 대기 습격 생성(갈래 미적용), `FinishRaid` 뒤 갈래 적용·사상자·문도 감소·연대기 경과. AI 대상이면 즉시 해결. `raid`가 최상위가 아니면 검증 오류.
- 저장: 대기 습격이 있는 채로 저장 → 불러오기 → 같은 시드로 같은 결과.
- 장기: 200년 시뮬레이션이 예외 없이 돈다(습격 자동 해결 포함), 기존 인구·세력 기준 유지.
- 화면: `UiScenario.RunTask16` — 습격 강제 → 습격 창 → 직접 지휘 → 일시정지 상태에서 아군 고르고 이동·공격 명령 → 진행 → 결과 창 → 연대기 경과. 자동으로 맞서기도 한 번.

## 10. 구현 중 바뀐 점

- **경지 차이**: 여럿이 한 사람을 둘러쌀 수 있어 1:1 결투의 경지 보정(1.1)으로는 절정 고수가 졸개 열 명에게 졌다. 전투는 경지 보정 1.2를 쓰고, 회피 확률에 경지 차 × 0.05를 양방향으로 더한다(낮은 상대의 손속은 더 잘 피한다). `Master_BeatsMob`으로 고정.
- **자리 지키기**: 이동 명령으로 자리를 잡은 단위는 그 자리에서 닿는 적만 친다(망루 위 궁수처럼). 새 명령을 받으면 풀린다.
- **처음에는 멈춤**: 전투 화면은 일시정지 상태로 열려, 시작 전에 자리를 잡을 수 있다.
- **연대기**: 플레이어 장원 습격은 연대기 종류 `Raid`(중요도 2)로 남고, AI끼리는 `Event:{사건 id}` 줄에 결과가 붙는다.
- 사건 효과를 최상위부터 하나씩 실행하며 `EventContext.ChoiceIndex`·`EffectIndex`를 기록한다(습격을 미룰 때 갈래 효과를 다시 찾기 위해).
